An entry for make.fun's [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) bounty ($2 in USDC): a program that writes one monologue of exactly 100 words, spoken by a fantasy villain who is secretly just very tired.

`main.py` (Python 3.13, standard library only) writes the monologue to `/output/entry.txt`. The weariness is never announced — the words tired and weary appear nowhere — it lives in the deflections: nobody brings tea before noon, the ravens unionised, the dragon left for a warmer cave and took his best cloak. He is still a villain with a history (nine kingdoms, three cursed moons) and a scheme (the tower, the chair, the dark), and the last line lands the turn: win, if you must — he will still be here, waiting on a roofer. The output is deterministic: every run writes the same monologue, exactly 100 words and 547 characters as the gate requires (1–600 characters, not only white space).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
